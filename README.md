# Jogo do Número Secreto

Um projeto simples em HTML, CSS e JavaScript para praticar lógica e interação com a página. O jogador tenta descobrir um número sorteado entre 1 e 50. Após cada palpite, o jogo indica se o número secreto é maior ou menor, conta as tentativas e permite iniciar outra rodada ao acertar.

## Como usar

Abra `index.html` no navegador. Digite um número de 1 a 50 e clique em **Chutar**. O botão **Novo jogo** é liberado após um acerto. O projeto carrega fontes do Google Fonts e usa ResponsiveVoice para falar as mensagens em português; a voz depende desse serviço externo.

## Arquivos

- `index.html`: estrutura da página e controles.
- `style.css`: apresentação visual.
- `app.js`: sorteio, verificação dos palpites, mensagens e reinício.
- `img/`: imagem usada na interface.

Este é um exercício de programação e não faz parte dos projetos de análise de dados do perfil.
